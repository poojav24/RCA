# NZCC Client Demo — Video Recording Script

Use with the live app (`python server.py` → http://127.0.0.1:8001/).

Full page-by-page narration is in the chat history / previous DEMO_VIDEO_SCRIPT content.

## Quick start
1. `python server.py`
2. Open the printed URL
3. Record Dashboard → Live Investigation → Active Alerts → RCA → Knowledge → AI Search → Metrics → Logs → ServiceNow → Analytics → Roadmap → Settings

## Closing line
Near Zero polls Zabbix every poll interval, persists data in SQLite, runs AI RCA with metrics/logs/history, and learns from resolved incidents in the Knowledge Repository.
